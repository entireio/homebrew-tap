# Entire Homebrew Tap

Private Homebrew tap for the Entire CLI.

## Installation

Stable:

```bash
brew install --cask entireio/tap/entire
```

Nightly:

```bash
brew install --cask entireio/tap/entire@nightly
```

## Updating

```bash
brew update
brew upgrade entire
```

## Uninstall

```bash
brew uninstall entire
brew untap entireio/tap
```
