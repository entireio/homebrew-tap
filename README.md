# Entire Homebrew Tap

Private Homebrew tap for the Entire CLI.

## Installation

First, tap the repository:

```bash
brew tap entireio/tap
```

Then install:

```bash
brew install --cask entire
```

## Updating

```bash
brew update
brew upgrade entire
```

## Uninstall

```bash
brew uninstall entire
brew untap entireio/tap
```
